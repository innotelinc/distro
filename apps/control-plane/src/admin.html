Gateway keys

Every account spends through a key of its own. A pass runs at boot and on a timer: an account with no key is minted one, and a key the gateway rejects — or that several accounts share, so its spend cannot be attributed — is rotated. Check shows the verdicts without touching anything.

Pools

A provider is a connection; a pool is a place inside it. local is a folder on this host, nfs is a mounted share (checked against the mount table, so a dead share says so), and gcs is a Google Cloud Storage bucket reached with a service account. Probe writes, reads back and removes one object — the only honest answer to "is it wired".
