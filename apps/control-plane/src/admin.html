What Distro is

Distro — BuilderOps is the platform's control plane for the shared AI gateway (OmniRoute): it owns who may call the gateway, how much they may spend, and what it cost — users, per-day quotas (requests / tokens / USD), gateway API keys, and a usage + spend ledger.

It is the operations and billing surface of the estate: identity comes from Cerulean Authentik, metering from the gateway, prices from a curated rate table, and build operations from Olympus Studio — all rendered here so an operator never needs a shell.

The relationship with Olympus Studio is one loop: Studio is where an app is built, and every model call that build makes is spent on a Distro-issued per-user gateway key — so quota is gated before each turn and usage recorded after it. Studio's build queue is mirrored here read-only, which is the pipeline below; the same flow is drawn on Studio's own /admin panel, one click away.

Integrations
  • Cerulean AuthentikSSO (OIDC + PKCE) — identity and admin groups
